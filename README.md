# Wordle
Wordle built with Python

Features
- UI with 6x5 grid with color-changing tiles that can hold 5 letter words in each row.
- User can guess up to 6 words.
- Tiles light up yellow if guessed letter is in the correct word.
- Tiles light up green if guessed letter is in the correct position in the correct word.
- Ends game if all tiles are green.
- Ends game if 6 guesses are up and tells user the correct word.

Technologies
- Python
- Libraries: Tkinter, Random, Requests

What I Learned:
- Object-Oriented Programming
- UI design with Tkinter
- Keyboard typing
